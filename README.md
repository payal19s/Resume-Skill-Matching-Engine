# Resume & Skill Matching Engine

## Overview
This project was developed during my internship at Graphura India Pvt. Ltd. The system helps automate the resume screening process by matching candidate resumes with suitable internship roles using Data Analytics and Machine Learning techniques.

## Features
- Resume data extraction and organization
- Rule-based skill matching
- Candidate fit score calculation
- AI/ML role recommendation
- Interactive dashboard for hiring insights
- Top role match prediction

## Technologies Used
- Python
- Machine Learning
- Power BI
- MS Excel

## Project Workflow
1. Collected and cleaned resume data
2. Converted unstructured data into structured format
3. Applied rule-based matching logic
4. Built ML models for role prediction
5. Created dashboard for candidate analysis

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
